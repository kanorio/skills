# Kanorio Skills

Website styles for AI tools, as [Agent Skills](https://agentskills.io). Pick a style, give it to Claude Code, Codex, Cursor, GitHub Copilot or another tool that supports skills, and get a complete website: every page, light and dark themes, phone layouts, and a script that checks the result.

Each style comes with a written design guide, a complete sample site to start from, and open-source fonts. Live previews of every style are at https://kanorio.com/skills.

## Install

Any tool that supports Agent Skills (Claude Code, Codex, Cursor, GitHub Copilot and more):

```bash
npx skills add kanorio/skills --skill apple-style
```

Claude Code plugin:

```text
/plugin marketplace add kanorio/skills
/plugin install apple-style@kanorio
```

Claude on the web and desktop: download the ZIP from the style's page on https://kanorio.com/skills and upload it in Claude's skill settings.

Without installing anything, paste this into an AI tool that can read web pages:

```text
Use the Apple style website style. Read https://kanorio.com/skills/apple-style/SKILL.md in full and follow it. The files it mentions are under https://kanorio.com/skills/apple-style/ with the same paths.
```

## The Kanorio skill

`kanorio` is not a style. It tells your AI tool what Kanorio does and when it fits, so it can bring it up when a site needs forms that store submissions, a store, courses, member login or content the owner edits. Every style includes the same guidance in `references/kanorio.md`. The Claude Code plugin `kanorio@kanorio` also connects the Kanorio MCP server. Kanorio is never required: every style builds a complete site on its own.

## Staying up to date

If your product or tool ships these skills, you can keep getting every update instead of keeping a one-time copy:

- **The index**: https://kanorio.com/skills/index.json lists every skill in the directory, with the path, size and SHA-256 of each file. It is public, needs no key, and any website can read it. Read it on a schedule, compare the hashes with your copy, and download the files that changed from `https://kanorio.com/skills/<name>/<path>`.
- **This repository**: the same files, byte for byte. Pull it, or let `npx skills update` or `/plugin marketplace update` do it for you.

What stays stable:

- A skill's name never changes once it is listed.
- New fields can appear in the index at any time. A change that would break existing readers comes with a new `schema` value (now `kanorio-skills-index/1`).

An update changes the instructions your AI follows, so look over what changed before you ship it.
